FHIR Sample Code

本公開範例網站由衛生福利部之「112年度智慧健康雲專案辦公室營運案專案」經費支應下建置，本範例網站分為三個部分，包含符合新版 TW Core IG 之 FHIR Server 與 FHIR Client 的原始碼範例，以及問答專區。

第一個部分為 FHIR Client的範例網站，提供醫療資訊開發者進行系統開發原始碼之參考，其資訊包含以供完成設計之20個TW Core Resources之資料操作範例，包含Resource查照之共用參數、請求方法、查詢參數、以及CRUD的不同種程式語言開發範例，系統開發語言則包含PYTHON, JAVA, 與C#。

第二個部分為FHIR Server的範例網站，提供伺服器需求者進行開放程式碼之伺服器安裝說明、架構微調方法，其包含HAPI FHIR Server (Linux and Windows), Smart on FHIR, Burni FHIR (Linux), 與 LinuxForHealth FHIR (Linux)。上述四個開放資源皆在Apache 2.0 授權規範下，FHIR Server的範例網站完整說明四個不同的伺服器之安裝流程，提供相關單位參考。

第三個部分為問答專區，相關使用者可以在問答專區進行資訊的提問，將由智慧健康雲專案辦公室FHIR技術團隊提供回應。
