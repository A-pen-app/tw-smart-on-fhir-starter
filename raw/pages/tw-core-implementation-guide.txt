臺灣核心實作指引
臺灣核心實作指引（Taiwan Core Implementation Guide，簡稱TW Core IG）採用HL7® FHIR® standard IG 建置方法，在 FHIR R4.0.1 之標準基礎上，並參考國際病人摘要（International Patient Summary，IPS）1.1.0-CI Build 及美國核心實作指引（US Core Implementation Guide），定義適用於臺灣健康照護資料交換需求的 Resources。
