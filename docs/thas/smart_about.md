### 什麼是 SMART
SMART on FHIR 是一種結合 HL7 FHIR 標準與 OAuth2、OpenID Connect 等安全協定的醫療資料互通架構，旨在促進醫療應用的開發與部署，提升醫療資訊系統的整合性與靈活性。

### 起源與發展
• 2009 年：《新英格蘭醫學雜誌》提出電子病歷（EHR）作為平台的概念，倡導其作為應用程式開發的基礎，以實現更廣泛的醫療資料共享。
• 2011 年：SMART Apps 的願景明確，目標是開發可在不同 EHR 系統間運作的應用程式，解決系統孤立的問題。
• 2013 年：SMART on FHIR 概念形成，專注於運用 HL7 FHIR 標準，提升醫療應用開發水平，促進資料互通。
• 2014 年：HL7 FHIR 首次實現，推動 SMART 與 FHIR 的整合，為醫療 IT 解決方案奠定技術基礎。
• 2016 年：美國精準醫療計畫認可 SMART on FHIR，將其應用於推進個人化醫療，強調其在精準醫療領域的重要性。

### 核心概念
1. 身分與存取管理：採用 OpenID Connect 協定，確保應用程式安全地請求臨床資料，並透過授權範圍限制存取權限，保障使用者隱私與資料安全。
2. 資料存取：基於 FHIR 標準，使用 FHIR REST API 讀取與更新臨床資料，確保資料交換的結構化與一致性，同時結合身分管理，保護資料在傳輸與存取過程中的安全。
3. 啟動流程：提供基於 Web 的標準化啟動流程，應用程式可透過標準化 URL 快速啟動，與電子病歷系統無縫整合，讀取結構化的病人資料與臨床資訊，支持應用程式的運行。

### 互通架構
SMART on FHIR 的互通架構利用資料存放區存取臨床資料，並在 FHIR 介面上新增安全層，包括 OAuth2 和 OpenID Connect，實現與醫院資訊系統的深度整合。這種架構提升了醫療系統的資料互通性與共享效率，支持靈活的資料存取需求，同時確保隱私保護。
整體而言，SMART on FHIR 的發展展示了從概念到全球標準的成功歷程，透過技術進步與政策支持，已在全球醫療產業中獲得廣泛應用與認可。未來，SMART on FHIR 將持續推動醫療資料互通性，成為全球健康 IT 創新不可或缺的一部分，為醫療產業帶來更智能化、高效化的數位解決方案。
