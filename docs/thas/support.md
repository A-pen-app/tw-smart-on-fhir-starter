# 提問須知
歡迎使用本網站支援中心，為確保您的權益，請務必詳閱以下說明內容，再行提問：

- 依個人資料保護法，未經您同意，衛福部資訊處不會將您的個人資料提供他人使用，僅提供承辦單位業務需要聯繫使用。

- 依行政程序法第173條規定，有下列情形之一者，衛福部資訊處將不予處理：
- a. 無具體內容或未具真實姓名及Email者。

- b. 同一事由，經予適當處理，並已明確答覆後，而仍一再陳情者。

- c. 非主管陳情內容之機關，接獲陳情人以同一事由分向各機關陳情者。

- 提問案件處理期限，為系統收到信件後「6個工作天(扣除例假日)」為原則。
