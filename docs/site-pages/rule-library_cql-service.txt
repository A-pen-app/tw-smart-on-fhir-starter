CQL 測試環境（CDS Hook Service）
CQL 測試環境
提供使用者上傳 CQL 及病患資料透過 CDS Service 進行測試。
CDS Hooks Sandbox 測試流程
一、開啟 CDS Hooks Sandbox
二、設定 CDS Services
1. 按齒輪設定
2. “Add CDS Services”
3. Save
三、設定 FHIR Server 及 Patient
1. 按齒輪設定
2. “Change FHIR Server”
3. 輸入 Patient Resource ID
4. Save
四、展示結果
