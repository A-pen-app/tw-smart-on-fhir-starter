# 我們在 FHIR 上能運用哪些資料

查詢日期：2026-09-24。來源：THAS 沙盒 `https://thas.mohw.gov.tw/v/r4/fhir` 的實際筆數（`thas/probe/resource-counts.json`），以及 TW Core IG v1.0.0 套件內容。

**先分清楚三件事：**

| 層次 | 意思 | 範圍 |
|---|---|---|
| FHIR 規格 | 標準本身定義的資料類型 | 146 種 Resource |
| TW Core IG | 台灣規定「至少要能表達」的資料 | 約 30 種 Resource、共 99 個 Profile |
| 沙盒實際有資料 | 現在能拿來測試的 | 59 種有資料，其他是空的 |

## 2. TW Core IG 定義的資料（台灣正式要求）

**臨床資料**

| 類別 | Profile |
|---|---|
| 病人與人員 | Patient、Practitioner、PractitionerRole、RelatedPerson、Organization（含醫院科別、政府、公司 3 種子類型）、Location |
| 就診與診斷 | Encounter、Condition、Procedure、AllergyIntolerance、Immunization |
| 檢驗與報告 | Observation（22 種，見下）、DiagnosticReport、Specimen、ImagingStudy、Media |
| 用藥 | Medication、MedicationRequest、MedicationStatement、MedicationDispense |
| 照護 | CarePlan、CareTeam、Goal、ServiceRequest |
| 文件與交換 | Composition、DocumentReference、Bundle（含 Document、Message 兩種）、MessageHeader、Provenance |
| 其他 | Coverage（保險）、QuestionnaireResponse（問卷）、Device（植入式裝置） |

**Observation 的 22 個細分類**（App 最常用）

- 生命徵象：Vital Signs、血壓、平均血壓、心跳、呼吸、體溫、血氧、身高、體重、BMI、頭圍
- 兒科：兒童 BMI-for-age、體重身長比、頭圍百分位
- 檢驗檢查：Laboratory Result、Clinical Result、ECG（心電圖）
- 生活與偏好：吸菸狀態、職業、懷孕狀態、懷孕意願、性傾向、照護經驗偏好、治療介入偏好
- 其他：Screening Assessment（篩檢評估）、Simple Observation

**另外還有**：55 個 ValueSet 與 30 個 CodeSystem（台灣用的代碼表，如 ICD-10-CM/PCS 中文版、健保用藥品項、職業代碼）、6 個 ConceptMap、地址擴充欄位（縣市、路、巷、弄、號、樓、室等）。詳見 `twcore-ig/package/package/`。

| 保險/申報輔助 | Coverage、Claim、ExplanationOfBenefit |

## 4. 使用上要注意的限制

1. **沙盒資料是 Synthea 合成資料（美式），不是台灣真實資料。**
   筆數多，但代碼多為 LOINC/SNOMED，不一定符合 TW Core 的欄位與代碼（例如身分證字號、健保用藥代碼、ICD-10-CM 中文版）。所以「沙盒查得到」不等於「符合 TW Core」。
2. **裡面另有一批 `TWIDIR` 開頭的病人**（疑似傳染病通報 IG 的測試資料）。我們抽到的那位沒有檢驗值。開發前建議先查該病人有哪些資料，或改選其他病人。
3. **沙盒不檢查權限（已實測）。** 用只有 `patient/*.read` 的 token 也能讀 Practitioner、Organization、Location，甚至能讀其他病人的資料；不帶 token 也能讀寫。真實醫院不會這樣，開發時請自己遵守最小權限，詳見 `沙盒驗證結果.md`。
4. **資料量不代表品質。** Observation 有 40 萬筆，但大多是 Synthea 產生的生命徵象與檢驗，種類分布不一定貼近台灣臨床。
5. **真實醫院的資料範圍會比沙盒小。** 各院實際支援哪些 Resource，看該院的 CapabilityStatement（`/metadata`）。
6. **寫入（已實測）**：沙盒可以新增資料（POST 回 201）、也可以刪除，而且不需要寫入權限。這是公開共用的沙盒，請勿放真實資料、測完請刪除。真實醫院需要 `patient/*.write` 或 `patient/*.cruds` 之類的權限。

## 5. 怎麼自己查

查某種資源有多少筆：

```
GET https://thas.mohw.gov.tw/v/r4/fhir/Observation?_summary=count
```

查某位病人有哪些資料（把病人 ID 帶進去）：

```
GET .../Patient/<id>/$everything
```

（已實測可用，回傳多種資源並分頁。）

依代碼查檢驗值（例如 HbA1c 的 LOINC 4548-4）：

```
GET .../Observation?patient=<id>&code=http://loinc.org|4548-4&_sort=-date
```

查某資源支援哪些搜尋條件：看 `/metadata` 內該資源的 `searchParam`，或看 `twcore-ig/package/package/SearchParameter-*.json`。
